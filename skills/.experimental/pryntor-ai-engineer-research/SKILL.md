## Workflow

1. Inspect live official docs and schemas. Prefer MCP search/fetch if enabled, otherwise the public metadata. Never invent tool or application fields.
2. Read-only shortlist: python catalog.py --area 'Core / engineering' --limit 8, or append --input fixture.json for offline tests. It fetches only the official metadata, caps bytes, rejects redirects, deduplicates and emits a source hash. It is heuristic ranking, not research validation.
3. Validate each selected talk on its public page; distinguish summaries from speech. Automated transcripts can be inaccurate; cite verbatim passages only with verified source timestamps.
4. Record source URL, retrieval date, evidence confidence, venture, measurable hypothesis, baseline, cost, licences/consent, frozen holdout and independent reviewer (see PRY-199).
5. Changes require scope-limited review branch, local preflight, latest-head CI and human QA before production. No customer/student data, private transcripts, paid APIs, auto-renewing trials, ticket payments or unapproved outbound communications.
6. Attendee applications and external speaker CFP are DIFFERENT procedures. Show complete final details and obtain permission before any submission; restricted Hugging Face dataset needs authorized access.
